# Configure CAP LTER project details for a EML project entity

configure_caplter_project establishes an EML::project with the elements:
(1) personnel (CAP PI and Co-PIs), (2) project abstract (project
overview from CAP V proposal), and (3) funding (grant numbers for CAP I,
II, III, IV, and V).

## Usage

``` r
configure_caplter_project()
```

## Value

establishes in the R environment a EML::project entity specific to the
CAP LTER.

## Details
